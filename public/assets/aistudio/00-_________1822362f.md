## 1. 风格圣经（唯一标准，不许偏离）

- 以 `00-风格圣经-demo图.png` 为准，成品必须长得和这张图一样。
- 低饱和水墨像素夜；玩家周围唯一暖色灯笼光；朱红只留给精英 / Boss。
- 细腻像素，不是粗糙大像素；水墨柔边；面部、衣服有细节。
- 场景只限 demo 图里的元素：墓碑、断墙、竹子、草丛、土路、满月、雾、绿色宝石经验拾取物。
- UI：左上羊皮纸 HP / LV / TIME，右上 COINS / EXP。

| 暖黄系（约 5%） | 暗琥珀 #B97F22 | 灯笼暖黄 #E8B34A | 灯芯亮 #F5D98A |

经验绿（功能色，只给地面经验宝石，画面占比 <1%，以 demo 图为准）：#57B96A、亮 #8FD694、暗 #3D8A4E。不要和灰绿系混用，草丛也不许用经验绿。

色板用法：朱红只给精英的红眼和精英僵尸胸前的红色圆形印章，普通敌人、场景、UI、少年身上都不许有红；生旦妆面同样不用朱红；一帧朱红超过 5% 先删装饰和特效。双世界只动参数不换色板。

## 3. 细颗粒像素规格

- 主角和 Boss 96×96，普通怪 / 精英 64×64。
- 色板内做 2–3 级水墨过渡；描边是细的、选择性的，不套统一粗黑边。
- 脸和衣纹细节要能看清；走路 6–8 帧；变脸由 3 个关键姿势 + 过渡帧构成。
- 验收加两项：眯眼测试、放大 200% 看粒度。Demo 约 110–150 帧，省内容不省粒度。

## 4. 角色 / 怪物 / 场景设定

- 主角：提灯少年（灰蓝袍、黑帽、手提暖黄灯笼）。
- 另一世界：生（净面快剑）、旦（骨白水袖）；只用 18 色，妆面不用朱红，灯不离人。
- 怪物：灰白雾状幽魂（黑色椭圆眼口）、僵尸（深灰袍、黑帽、黄色额头符、双臂前伸）。
- 精英：红眼大幽魂、红眼僵尸（胸前红色圆形印章）。
- 场景：俯视夜晚墓园、满月、墓碑、断墙、竹子、草丛、土路、绿色宝石。
- 2026-11-06 新增（任务 5 讨论定稿）：场景增加其余冷色光源——坟头鬼火（冷绿 / 冷灰）、墓旁长明灯、满月月光；做得暗、冷、小，灯笼仍是最亮最暖的那个。规则 2 改为熄灯期间站在任意光里都算（冻住的灯笼光圈 + 新光区），这些光熄灯时一直亮着。

## 6. 方案要点

- 三合一：规则 + 变脸 + 双世界。先做最小完整 Demo（1 张图、2 个行当、9 条规则抽 3、10 个升级、20 分钟 Boss），再扩展（4 行当、更大规则池、理智系统、20+ 升级）。
- 幸存者循环：移动 + 自动攻击 → 杀怪得经验 → 升级三选一 → 20–30 分钟一局 → 元成长与重玩。
- 工具：dsh + DeepSeek V4.1 Flash 主力；Qoder + Qwen3.8 Flash 复核；WorkBuddy 做文档 / Steam 文案；Doubao 头脑风暴、讲代码。像素编辑另需 Aseprite（$19.99）或免费 Pixelorama。
- 喂料分层：先喂开工包，让 agent 复述范围和禁区；手册放 docs/ 按需读；demo 图 + 18 色当风格文件。不喂调研报告、竞品截图、已作废方案（朱红纸影 / 年画门神、戏班学徒主角、无面新娘等）。
- 审核：Muse 是总控，审 PR 对照开工包验收清单、demo 图、色板和范围冻结；用户是最终试玩裁判（手感 / 好玩 / 样子）。
- 开工包见 `开工包/kai-gong-bao.md`（Godot 4 + GDScript，1280×720，数据全放 JSON，任务 0–5 各带验收清单）。
- 当前进度（2026-11-06）：任务 4 已结；任务 5（固定 3 条规则）PR #9 有条件通过，待补画面证明。
